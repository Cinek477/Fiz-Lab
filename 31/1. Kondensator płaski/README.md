Karta zawiera 20 wierszy trzech profili i 50 punktów mapy poza elektrodami, parametry stanowiska i miejsce na szkic.
Liczba stron karty / szablonu: **5 / 6**. Daty pozostają puste.

Z folderu `Tworzenie/` tego wariantu:

```powershell
tectonic 31_A_karta.tex --outdir ../PDF
tectonic 31_A_szablon.tex --outdir ../PDF
```

Overleaf: **XeLaTeX**, plik główny `31_A_karta.tex` albo `31_A_szablon.tex`.
Poza ZIP-em źródła korzystają z `../../Wspolne/`; nie przenoś samego pliku LaTeX.
Odtworzenie wszystkich wariantów opisano w README ćwiczenia.
