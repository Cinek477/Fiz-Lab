# Dane do szablonu — ćwiczenie 71

[Szablon i generator](../README.md)

Publiczny folder `szablon/` zawiera puste pliki: `parametry.json`, `pomiary.json`
i `ekstrema.json`. Służą do wpisania parametrów stanowiska, odczytów oraz par maksimów.
Do pustego dokumentu użyj generatora z opcją `--template`.
Do własnych danych skopiuj trzy pliki do osobnego folderu, uzupełnij je
i przekaż generatorowi przez `--input-dir`.

Zapisana wcześniejsza seria, źródłowe karty, wyniki i wykresy pozostają lokalne,
wykluczone przez `.gitignore`. Nie stanowią publicznego przykładu sprawozdania.
