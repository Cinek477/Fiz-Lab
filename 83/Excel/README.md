# Pomiary — ćwiczenie 83

[Opis ćwiczenia](../README.md) · [Pełna instrukcja](../../Excel/README.md)

1. Otwórz [83_pomiary.xlsx](83_pomiary.xlsx) i zapisz kopię ze swoimi pomiarami.
2. Wypełnij żółte pola w ustawieniach oraz tabelach. Zapisz i zamknij arkusz.
3. Przeciągnij zapisany plik na **[utworz_sprawozdanie.cmd](utworz_sprawozdanie.cmd)**.

Obok zapisanego arkusza powstanie folder `Wyniki/83/` z obliczeniami,
wykresami i paczką sprawozdania do Overleaf. PDF powstaje przy dostępnym Tectonicu.
Wymagany jest `uv` lub Python z bibliotekami opisanymi w pełnej instrukcji.
